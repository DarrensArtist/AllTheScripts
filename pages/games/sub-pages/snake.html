Proof of concept · Incomplete

Project Snake

An early Unity WebGL deployment test—not a finished or meaningfully playable game.

What I was proving

I wanted to confirm that I could package a Unity project for WebGL, place its generated files on a static GitHub Pages site and connect the loader, data, framework and WebAssembly paths correctly.

The build remains here because that deployment worked. It records a useful technical milestone, even though the game itself was not developed into a complete experience.

Known limitation

There is no complete gameplay loop. More design, controls, presentation, testing and polish would be required before this should be described as a game.

What the experiment demonstrated

Build packaging

Static hosting

Honest scope

A successful deployment test is useful evidence without being presented as a completed game.
