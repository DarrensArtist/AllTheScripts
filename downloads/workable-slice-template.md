# Workable slice

## Result

What concrete, observable outcome will exist when this slice is complete?

## Included

- Behaviour or content included in this slice.
- Files, scenes or modules expected to change.

## Excluded

- Adjacent work intentionally left for a later slice.

## Dependencies

- Inputs, assets, decisions or earlier work required first.

## Acceptance checks

- [ ] The result works in its real context.
- [ ] Important failure and unsupported states are handled.
- [ ] Documentation matches the implementation.
- [ ] Unrelated work remains unchanged.

## Completion boundary

Stop when the acceptance checks pass. Record remaining work separately rather than expanding the slice.
