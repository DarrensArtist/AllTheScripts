Why This Exists

Less theory, more useful starting points.

The aim is to publish assets that shorten the distance between an idea and a first playable version: small prototypes, templates that remove admin friction, and scripts that can be adapted into real projects.

What To Open First
  • Games: try the live Snake build and inspect how it is presented.
  • Documents: use the planning material as a base for production work.
  • Scripts: follow the reusable code direction planned for future releases.
