Unity Project Lessons

Play a small Unity project, then learn how to build the same thing.

This site is a teaching portfolio built around simple playable projects. Each project is meant to prove a mechanic, show the process behind it, and give other developers a practical route to recreate it.

Browse projects Open Snake
How this portfolio works

Short projects with real learning value

  • Play it: open the project page and test the build or current prototype state.
  • Study it: read the systems, mistakes, and build notes.
  • Rebuild it: use the walkthrough structure as a template for your own Unity practice.
